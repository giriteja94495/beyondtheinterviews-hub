The kind of data stored in an agent's memory typically falls into three buckets: 


- Semantic memory (stable facts and preferences of the user)  
- Episodic memory (storing specific past events/episode/decisions)  
- Procedural memory (store reusable workflows/playbooks as to how agents should behave.)
